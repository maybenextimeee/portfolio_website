# Портфолио

Мой персональный сайт-портфолио: обо мне, проекты, стек, контакты.

**Сайт:** [maybenextime.ru](https://www.maybenextime.ru)

## Что на сайте

- Тёмная тема по умолчанию и светлая по кнопке, выбор запоминается
- Мягкий фон «рассвет»: звёзды, сияние, облака, которые чуть сдвигаются за курсором
- Анимации появления играют сами, когда блок попадает на экран; при быстрой прокрутке они ускоряются, а пролистанные сразу доигрываются
- Фото открываются на весь экран с плавным переходом, листаются стрелками и свайпом
- Промо-видео Night Survivors, которое играет только пока его видно
- Адаптивная вёрстка под телефон, кнопка «Наверх» внизу страницы

## Стек

- HTML + CSS + JavaScript, без фреймворков и конструкторов
- Шрифт Manrope, лежит локально (woff2), без Google Fonts
- Хостинг: GitHub Pages, свой домен

## Структура

```
portfolio/
├── index.html            — страница сайта
├── css/
│   └── style.css         — стили и обе темы
├── js/
│   ├── main.js           — тема, облака, шапка, видео, счётчики цифр, кнопка «Наверх»
│   ├── play.js           — анимации появления блоков
│   └── lightbox.js       — просмотр фото на весь экран
├── fonts/                — Manrope (кириллица и латиница)
├── img/                  — фото
├── video/                — промо-видео Night Survivors
├── favicon.ico           — иконка вкладки (16, 32, 48)
├── icon-192.png          — иконка побольше (Android, поисковики)
├── apple-touch-icon.png  — иконка для iPhone (180×180)
├── og-image.png          — картинка для превью ссылки в Telegram и соцсетях (1200×630)
├── CNAME                 — свой домен для GitHub Pages
└── .nojekyll             — отключает Jekyll, сайт отдаётся как есть
```

## Запуск локально

Сайт статический, сборка не нужна. Если открыть `index.html` просто файлом, браузер может
не подхватить шрифты, поэтому лучше через локальный сервер:

```bash
python -m http.server 5500
```

и открыть http://localhost:5500.

## Деплой

Каждый push в ветку `main` сам выкладывается на GitHub Pages
(Settings → Pages → Deploy from a branch: `main`, `/`), HTTPS включён.

Домен куплен на reg.ru, DNS держит Cloudflare (записи в режиме DNS only, без прокси):
`A @` → адреса GitHub Pages, `CNAME www` → `maybenextimeee.github.io`.

Раньше сайт жил на Vercel, но у многих российских провайдеров Vercel виснет без VPN,
а GitHub Pages открывается нормально.
