Мой персональный сайт-портфолио: обо мне, стек, проекты, контакты.

**Живая версия:** _скоро — задеплою на Vercel и прикручу домен_

## Стек

- HTML5 + CSS3 (без фреймворков и конструкторов)
- Адаптивная вёрстка, тёмная тема
- Хостинг: Vercel

## Структура

```
portfolio/
├── index.html      — страница сайта
└── css/

```

## Запуск локально

Открыть `index.html` в браузере — этого достаточно, сайт статический.
