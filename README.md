# Портфолио

Мой персональный сайт-портфолио: обо мне, стек, проекты, контакты.

**Сайт:** [maybenextime.ru](https://www.maybenextime.ru)

## Стек

- HTML5 + CSS3 + JavaScript (без фреймворков и конструкторов)
- Адаптивная вёрстка, тёмная тема, анимации при прокрутке
- Хостинг: Vercel, свой домен

## Структура

```
portfolio/
├── index.html      — страница сайта
├── favicon.svg     — иконка вкладки
├── css/
│   └── style.css   — стили
└── js/
    └── main.js     — меню, анимации, эффекты
```

## Запуск локально

Открыть `index.html` в браузере — сайт статический, сборка не нужна.

## Деплой

Каждый push в ветку `main` автоматически выкладывается на Vercel.
